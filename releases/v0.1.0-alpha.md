# Solcore v0.1.0-alpha

Initial alpha release of the Core Solidity compiler implemented in Rust.
This prototype is not ready for production use.

- Every source file must begin with `pragma solcore;`. Solidity also uses the
  `.sol` extension; the compiler, language server and editor integrations use
  the pragma to tell the two languages apart.
- Native `solcore` compiler, `solcore-fmt`, and matching standard library.
- Compiler-integrated language server: editors start `solcore lsp` over stdio.
- Separate VS Code VSIX, Neovim/Vim plugin and Emacs mode packages.
- Browser playground with compiler and LSP WebAssembly, solc and Sonatina
  backends, and local EVM execution.

Download only an archive matching your OS and architecture. Available platforms
are the ones attached to this release; source is also included. Check downloaded
files against `SHA256SUMS`, extract the entire archive, and keep `std/` next to
the executable. `solcore-driver` and `solcore-lsp` remain available for existing
configurations. No native executable is bundled in the editor packages.

The online playground is deployed separately from the attached, versioned
playground archive. Its `/release.json` identifies the deployed compiler version
and source commit. See `docs/releasing.md` in the source archive for build,
installation and deployment details.
